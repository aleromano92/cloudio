# 0001 — Single Proxmox node on a repurposed laptop

We run everything on one 2013 Sony Vaio (i7-4500U, 16 GB max RAM, single SSD, no
ECC) rather than buying dedicated hardware. It is free, already owned, and the
constraints are the point of the learning exercise. Consequences: no redundancy at
the hardware level (mitigated by the backup routine — see README); Frigate and a
hungry personal cloud like Immich will likely force a move to an x86 mini-PC — the
repo is built so that move is a few hours, not a rebuild.
